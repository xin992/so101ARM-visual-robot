# 04 · 主程序与调参（step7_pick_place.py）

## 4.1 运行

```bash
# 真机运行（必须带 robot 参数）
python step7_pick_place.py --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=so101_follower

# 只检测不动臂（调试标定用，不需要 robot 参数）
python step7_pick_place.py --dry
```

> 首次跑之前：把机械臂手动摆成「自然前伸」的安全姿势；方块和框都放在桌面上、**离底座 0.3m 以内**（超出会报"框太远"）。

## 4.2 完整流程（8 步）

```
1) 检测方块 + 框（基座坐标系 3D 位置）
2) 使用初始检测的抓取点（跳过重检测，避免误检偏移）
3) 下抓：张开夹爪 → 缓慢下降（接触桌面/物块自动停）→ 闭爪
4) 抬升（LIFT_H，越过框边）
   └ 抬升后重新检测框（能拍到完整框，更新放置点；不可达/偏差大则用最初位置）
5) 平移到框上方（保持抬升高度）
6) 垂直下降到放置高度（PLACE_SAFE 上方）→ 张开夹爪 → 方块落进框
7) 抬升收尾
8) 回到起始姿态 → 断电（防止断电瞬间扭矩消失导致机械臂砸落）
```

## 4.3 核心原理

- **坐标**：所有 3D 位置都在**机械臂基座坐标系**（原点 = 底座中心，单位米）
- **像素→3D**：`pixel_to_3d` = 像素反投影射线 ∩ 桌面平面（单目 + 平面假设）
- **运动学**：`PyBulletKin` 用 PyBullet + 官方校准 URDF
  - FK：正运动学（注意读 `worldLinkFramePosition`，即 `getLinkState` 的 `st[4]`，不是质心 `st[0]`）
  - IK：**位置-only**（5 自由度臂同时约束位置+朝向很容易无解），多次随机重启 + 优先靠近当前姿态的解
- **夹爪**：SO-101 夹爪范围 0~100，**0=闭合，100=张开**（本项目用 18 抓、43 放）

## 4.4 全部参数表（脚本顶部配置区）

| 参数 | 本项目值 | 含义 / 怎么调 |
|---|---|---|
| `CUBE_H` | 0.030 | 方块高度（米） |
| `PRE_LIFT` | 0.05 | 预抓点高于抓取点的高度（米）；太小会导致"还没下降就夹" |
| `STEP_DUR` | 0.35 | 每步移动间隔（秒）；**调大=更慢**，电机卡顿就调大 |
| `TOL_DEG` | 3.0 | 到位允许误差（度） |
| `CONF` | 0.5 | YOLO 置信度阈值；检测不到就调低（0.2~0.3） |
| `GRIPPER_CLOSE` | 18.0 | 抓取时夹爪值（0=闭合）。用 `gripper_test.py` 实测"刚好夹住 3cm 方块"再减 5~10 |
| `GRIPPER_OPEN` | 43.0 | 张开值（100=全开）。够塞进方块即可，不用全开 |
| `LIFT_H` | 0.11 | 抓住后抬升高度（米）；撞框就调大 |
| `PLACE_LIFT_H` | 0.07 | 放完后抬升收尾高度 |
| `DIST_NEAR` / `OFFSET_NEAR` | 0.20 / -0.02 | 近点距离 & 该处抓取 x 偏移（两点校准，见 4.5） |
| `DIST_FAR` / `OFFSET_FAR` | 0.30 / -0.037 | 远点距离 & 该处抓取 x 偏移 |
| `CUBE_OFFSET_Y` | 0.007 | 中间位置时夹爪的左右(y)偏移 |
| `Y_OFFSET_SLOPE` | -0.30 | 左右偏移随物块位置(y)变化的斜率（偏右偏右就填负） |
| `PLACE_SAFE` | 0.035 | 放物块时停在框上方多高松手（米）；撞框就调大 |
| `BOX_OFFSET` | [-0.05, 0, 0] | 放框位置补偿（太前调更负，偏后调正） |
| `TOOL_OFFSET` | 0.11 | **腕部到夹爪中心距离（米）**，用尺子量；太小夹爪会插桌面 |
| `GRASP_LOW` | 0.02 | 抓取再低一点（米），让夹爪夹到方块中部而不是上半部 |
| `CUBE_CLASSES` | [red_fang, brown_fang] | 可抓的方块类别 |
| `BOX_CLASSES` | [bule_box] | 目标框类别 |
| `FLIP` | 0 | 摄像头方向修正（0/1/-1），所有脚本必须一致 |

## 4.5 抓取偏移的两点校准（关键调参）

夹爪倾斜角度会随「物块离底座的距离」和「左右位置」变化，所以偏移**不是固定值**，用两点线性模型：

**x（前后）偏移**：物块离底座越远，夹爪越偏前。
- 在 `DIST_NEAR`（20cm）处测一次：夹爪偏后填正、偏前填负 → `OFFSET_NEAR`
- 在 `DIST_FAR`（30cm）处测一次 → `OFFSET_FAR`

**y（左右）偏移**：物块偏右（+y）夹爪也偏右 → 斜率 `Y_OFFSET_SLOPE` 填负；偏左就填正。一个斜率管左右两边（线性对称）。

一次只调一个量，改 0.005~0.01 跑一次看一次。

## 4.6 速度调节

| 想 | 改 |
|---|---|
| 整体更慢 | `STEP_DUR` 调大（0.35 → 0.5/0.8） |
| 更平滑不抖 | `move_to` / `cartesian_move` / `joint_move` 的 `steps` 调大（28 → 50） |
| 夹爪动作更慢 | `move_robot(..., duration=0.5)` 的 `0.5` 调大 |

## 4.7 安全设计

- 抓取下降：**接触桌面/物块自动停止**再闭爪，不会硬戳
- 放框下降：用 `cartesian_move` **垂直下降**，不会往前甩撞框
- 框太远（>0.34m）：提示退出，不硬够
- 结束：**先回起始姿态再断电**，防止扭矩消失砸落
