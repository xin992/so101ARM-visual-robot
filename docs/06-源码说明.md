## 6.2 robot_lib.py 函数说明

| 函数/类 | 说明 |
|---|---|
| `find_urdf()` | 打印 lerobot 目录里的 URDF 路径 |
| `make_robot()` | 用命令行参数创建并连接机械臂（main 分支 API）；自动补 `motor_names` |
| `get_q(robot)` | 读 6 个电机当前值（5 臂=度，夹爪=0~100） |
| `move_robot(robot, target, duration)` | 发送目标到机械臂（`send_action`） |
| `wait_settled(robot, target, tol, timeout)` | 等待机械臂到位（卡顿时保险） |
| `detect_board(BOARD, gray)` | 用 ArucoDetector 检测标定板 marker |
| `board_pose_from_markers(BOARD, mc, mi, K, dist)` | 由 marker 恢复板子位姿（4×4） |
| `match_image_points(...)` | 备用（部分脚本用） |
| `PyBulletKin` | PyBullet 运动学封装 |
| └ `fk(q_arm_deg)` | 正运动学：5 关节角(度) → 4×4 末端位姿（读 link 原点 `st[4]`） |
| └ `ik(q, T_target)` | 逆运动学：**位置-only**、多次随机重启、优先靠近当前姿态；误差 < 2cm |

关键约定：
- `ALL_MOTOR_NAMES = [shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper]`
- 运动学只用前 5 个（臂关节）；第 6 个 `gripper` 范围 0~100（0=闭合）
- 末端 = `gripper_link`（wrist_roll 的子 link）

## 6.3 step7_pick_place.py 说明

| 函数 | 说明 |
|---|---|
| `save_debug(img, det, note)` | 存带标注图 + JSON 到 `debug/` |
| `T_cam2base(q)` | 当前关节角 → 相机在基座系的位姿（`fk(q) @ T_cam2ee`） |
| `pixel_to_3d(u, v, Tcb)` | 像素 + 桌面平面 → 基座系 3D |
| `detect(frame, Tcb)` | YOLO 检测 → 分组为 `cube`/`box` + 3D 点 + 朝向 |
| `grasp_pose(pt, yaw)` | 抓取/放置位姿（位置 + 高度偏移） |
| `_quat_slerp` | 手动四元数球面插值（scipy 新版没有 slerp） |
| `interpolate` | 备用（旧笛卡尔插值） |
| `pose_at(pos)` | 生成只有位置的 4×4 |
| `cartesian_move(q, T, steps)` | **笛卡尔直线移动**（沿直线插值，回位/垂直下降用） |
| `joint_move(q, q_target, steps)` | **关节空间移动**（精确回到指定关节角） |
| `move_to(q, T, steps, hold_gripper_close)` | 主移动函数：位置-only IK + 关节空间插值 |

主流程 8 步见 `04-主程序与调参.md`。

## 6.4 数据 / 标定文件格式

```
calib/
├── calib_intrinsics.npz   # K（内参矩阵）, dist（畸变）
├── calib_handeye.npz      # T_cam2ee（相机→末端 4×4）
├── table_plane.npz        # n（桌面法向量）, d（平面常数，n·x=d）
├── charuco_board.png      # 标定板图片
├── calib_imgs/            # 内参标定照片
└── handeye/               # 手眼姿态：pose_XXX.png + pose_XXX.json
```

- `pose_XXX.json`：`{"image": "...", "q": [6个电机值], "motor_names": [...]}`
- `debug/000_detect.json`：`{"cube": [[x,y,z], ...], "box": [...]}`（基座坐标系，米）
- `datasets/raw/`：YOLO 原始图片（jpg）

## 6.5 运行顺序汇总

```bash
python step2_intrinsics.py

python step3b_calib_handeye.py
python step4_calib_table.py

# YOLO 训练后
python step6_detect_preview.py     # 预览检测

# 日常运行
python step7_pick_place.py --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=so101_follower
```
