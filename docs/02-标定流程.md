# 02 · 标定流程（相机内参 / 手眼 / 桌面平面）

标定是整个项目**最关键、最容易出错**的部分。共 4 步，顺序不要乱：

```
标定板 → 相机内参 → 手眼标定 → 桌面平面
```

## 2.1 标定板（step1_charuco.py）

```bash
python step1_charuco.py
```

- 生成 `calib/charuco_board.png`（本项目用 **Charuco 板，7×5 格**）
- **A4 纸 100% 打印**，贴硬纸板
- **量一下黑色格子实际边长**，改脚本里的 `squareLength`（本项目实测为 `0.0375` m）
  > 格子边长写错 → 所有 3D 坐标整体缩放 → 手眼标定必然错（典型症状：`T_cam2ee` 出现 1 米以上的离谱平移）

## 2.2 相机内参（step2_intrinsics.py）

```bash
python step2_intrinsics.py
```

- 采集：标定板在相机前摆**不同姿态**（远近/倾斜/左右），空格拍照，至少 30 张，q 结束并自动计算
- 要求：板完整、清晰、不反光
- 输出：`calib/calib_intrinsics.npz`（K、dist）
- 判断：重投影误差 **< 0.5 很好，< 1 能用**

> **板子的 `squareLength` 必须和 2.1 一致**（本项目 `0.0375`），内参的焦距尺度依赖它。

## 2.3 手眼标定（step3a / step3b）

因为摄像头装在从臂上，必须标出「相机相对末端（腕部）」的固定变换 `T_cam2ee`。

### 2.3.1 采集（step3a_collect_handeye.py）

```bash
python step3a_collect_handeye.py --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=so101_follower
```

- 把标定板**平放在桌面上，胶带固定**，全程不动
- 用键盘控制机械臂摆姿态（板要完整可见）：
  - `q/w e/r t/y u/i o/p`：5 个臂关节正/反转
  - `g`：夹爪开合（**先张开**，别挡板）
  - `空格`：保存当前姿态（图像 + 关节角）
  - `x`：退出
- 保存 **15~20 个**姿态，姿态之间**变化要大**（远近/高低/倾斜）

> 连接时若进入校准流程，说明这台 id 没有校准文件，先完成一次校准（见 01-环境搭建 1.7）。

### 2.3.2 计算（step3b_calib_handeye.py）

```bash
python step3b_calib_handeye.py
```

- 内部流程：
  1. 检测标定板上的 marker，用 **marker → 板子位姿**（为什么不用 CharucoDetector，见 2.3.4）
  2. 用 PyBullet 正运动学（FK）得到每个姿态的末端位姿
  3. `cv2.calibrateHandEye`（TSAI / DANIILIDIS 都算，自动选更好的）
  4. 保存 `calib/calib_handeye.npz`
- **验证指标**：
  - ① 板位姿离散度：**< 2~3 cm**（核心指标）
  - ② 重投影误差：**< 10 像素**

### 2.3.3 为什么要用「marker 方案」而不是 CharucoDetector

OpenCV 4.13 里 `CharucoDetector` 对真实照片（有噪声/透视）经常**一个角点都检测不到**（默认内部参数过严），而单独的 `ArucoDetector` 却能稳定找到 15+ 个 marker。

所以 `robot_lib.py` 的 `detect_board` 用 **ArucoDetector 找 marker**，再用 `board_pose_from_markers` 恢复板子位姿：

- **marker id → 格子位置**公式（对 7×5 板验证过）：`k = 2*id + 1; j = k // X; i = k % X`（X=格列数）
- **角点顺序**：ArucoDetector 返回的角点按 `[2,3,0,1]` 对应板坐标系角点（顺序错会导致位姿错）
- 全部 marker 的角点一起 `solvePnP`，得到 `T_board2cam`

### 2.3.4 诊断工具

| 工具 | 作用 |
|---|---|
| `step3d_diag.py` | 检查单张图片的检测情况（marker 数、亮度等） |
| `step3e_order_test.py` | 测试 4 种角点顺序哪个 ① 离散度最小 |
| `step7_live.py` | 实时显示物体 3D 坐标，验证标定精度 |

## 2.4 桌面平面（step4_calib_table.py）

```bash
python step4_calib_table.py
```

- 原理：手眼采集时标定板**平放在桌面上**，板面 = 桌面，直接复用 step3 的数据，**不用重新采集**
- 输出：`calib/table_plane.npz`（法向量 n、常数 d，平面方程 `n·x = d`）
- **法向量强制朝上**（`n[2] < 0` 时取反），否则抓取时"抬升"会往桌子里钻
- 桌面高度 z 应接近 0（本项目约 -0.027 m，取决于底座安装高度）

## 2.5 标定质量检查清单

| 检查项 | 合格标准 |
|---|---|
| 内参重投影误差 | < 1 像素 |
| 手眼 ① 板位姿离散度 | < 2~3 cm |
| 手眼 ② 重投影误差 | < 10 像素 |
| 桌面法向量 | z 分量接近 +1 |
| `step7_live.py` 显示的物块坐标 | 和尺子量的 x/y 差几 cm 内 |

## 2.6 什么时候需要重新标定

- ❌ 只改 IK / 速度 / 夹爪参数 → **不用重标**
- ✅ 改过 `robot_lib.py` 的 `fk()`（正运动学）→ 重跑 step3b + step4
- ✅ 拆过/挪过摄像头 → 重跑手眼（step3）
- ✅ 换过标定板 / 改了 `squareLength` → 重跑 step2 + step3
- ✅ 机械臂底座挪动 → 重标桌面平面（step4）
