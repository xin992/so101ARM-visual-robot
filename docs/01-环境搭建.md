# 01 · 环境搭建（Ubuntu 虚拟机 + LeRobot）

本文从零配置一个能跑通本项目全部脚本的环境。

## 1.1 环境总览

| 项目 | 版本 / 说明 |
|---|---|
| 系统 | Ubuntu 22.04（虚拟机，VMware/VirtualBox 均可） |
| Python | 3.12（conda 环境） |
| LeRobot | GitHub main 分支（pip 显示的版本号是 0.6.1，但代码是 main 分支） |
| OpenCV | `opencv-contrib-python==4.13.0.92`（★ 不要装 5.x，见 1.5） |
| 其他 | ultralytics、scipy、pybullet |
| 机械臂 | SO-101 从臂（6 × Feetech STS3215 舵机，USB 串口 `/dev/ttyACM0`） |
| 摄像头 | 单目 USB 摄像头，装在从臂上（eye-in-hand），设备索引 0 |

> ⚠️ **最重要的认知**：你的 LeRobot 虽然是 0.6.1 版本号，但实际是从 GitHub `huggingface/lerobot` 的 **main 分支** clone 的，API 和正式 0.6.1 **完全不同**。后面所有代码都按 main 分支写，**不要照 0.6.1 的教程/API 查**。

## 1.2 创建 conda 环境

```bash
# 安装 Miniconda（如果还没有）
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
source ~/miniconda3/etc/profile.d/conda.sh

# 创建环境（Python 3.12）
conda create -n lerobot python=3.12 -y
conda activate lerobot
```

> 每次新开终端都要：
> ```bash
> source /home/x/robot_learning/conda/etc/profile.d/conda.sh
> conda activate lerobot
> ```
> 如果提示 `conda: command not found`，先执行 `source` 那行，或把 `conda initialize` 加到 `~/.bashrc`。
> 提示符变成 `(lerobot) x@...` 才说明环境激活成功。

## 1.3 安装 LeRobot（main 分支）

```bash
# 浅克隆 + 可编辑安装
git clone --depth 1 https://github.com/huggingface/lerobot.git ~/robot_learning/lerobot
cd ~/robot_learning/lerobot
pip install -e .
```

安装后确认：

```bash
python -c "import lerobot; print(lerobot.__file__)"
# 应输出 /home/x/robot_learning/lerobot/...
```

## 1.4 安装项目依赖

```bash
pip install ultralytics scipy pybullet
```

> **不要** `pip install "lerobot[kinematics]"`：它依赖 `placo`，在 Python 3.12 很难装。本项目的运动学直接用 PyBullet（见 `robot_lib.py` 的 `PyBulletKin`）。

## 1.5 安装 OpenCV（★ 版本很关键）

```bash
pip uninstall -y opencv-python opencv-python-headless opencv-contrib-python opencv-contrib-python-headless
pip install opencv-contrib-python==4.13.0.92
python -c "import cv2; print(cv2.__version__); print(hasattr(cv2,'calibrateHandEye')); import cv2.aruco; print('aruco ok')"
```

- ✅ 应看到 `4.13.x`、`handeye: True`、`aruco ok`
- ❌ **不要装 OpenCV 5.x**：
  - `cv2.calibrateHandEye`（手眼标定函数）在 5.x 中被移除
  - 旧的 `cv2.aruco` 遗留 API（如 `interpolateCornersCharuco`）在 4.13 也被移除，所以本项目用**新 API + marker 方案**（见 `02-标定流程.md`）
- 必须装 `opencv-contrib-python`（**contrib 版**）而不是 `opencv-python`：`cv2.aruco` 是 contrib 模块，普通版没有（会报 `module 'cv2' has no attribute 'aruco'`）

## 1.6 准备 SO-101 的 URDF

浅克隆的 lerobot 源码里没有 URDF。本项目使用官方校准版 URDF：

```bash
# 从 TheRobotStudio/SO-ARM100 官方仓库下载（jsDelivr 国内快）
mkdir -p ~/robot_learning/pick_place/urdf_so101/assets
curl -o ~/robot_learning/pick_place/urdf_so101/so101_new_calib.urdf \
  "https://cdn.jsdelivr.net/gh/TheRobotStudio/SO-ARM100@main/Simulation/SO101/so101_new_calib.urdf"
```

`assets/` 里的 13 个 STL 模型也一起下载（URDF 引用它们）。`robot_lib.py` 里的 `URDF_PATH` 指向这个文件。

> 这个 URDF 的关节名（`shoulder_pan / shoulder_lift / elbow_flex / wrist_flex / wrist_roll / gripper`）和 LeRobot main 分支的电机名**完全一致**，运动学直接可用。

## 1.7 机械臂校准（第一次连接）

连接机械臂时如果提示进入校准流程，说明没有这台 id 的校准文件：

```bash
python step3a_collect_handeye.py --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=so101_follower
```

- 校准文件按 **id** 保存（`~/.cache/huggingface/lerobot/calibration/robots/so101_follower/<id>.json`）
- **必须用同一个 `--robot.id`**，否则会以为"没校准"又进入校准
- 如果之前遥操作/旧版本校准过，main 分支的校准文件路径/格式不同，**需要重新校准一次**（校准 = 机械臂自动扫关节找行程，几分钟，一次即可）

## 1.8 端口与摄像头检查

```bash
ls /dev/ttyACM*          # 机械臂串口
ls /dev/video*           # 摄像头
python test_camera.py    # 摄像头方向测试（见下）
```

`test_camera.py` 用于确认摄像头画面方向：按 `0` 不翻转 / `1` 左右镜像 / `r` 旋转180°，找到和现实一致的模式。**所有采集/检测脚本里的 `FLIP` 值必须一致**（本项目最终用 `FLIP = 0`）。

## 1.9 常见环境问题速查

| 问题 | 原因 | 解决 |
|---|---|---|
| `conda: command not found` | conda 未初始化 | `source .../conda/etc/profile.d/conda.sh` |
| `python: command not found` | 没激活 conda 环境 | `conda activate lerobot` |
| `module 'cv2' has no attribute 'aruco'` | 装的是普通 opencv-python | 改装 `opencv-contrib-python` |
| `cv2` 没有 `calibrateHandEye` | OpenCV 5.x | 降级 `opencv-contrib-python==4.13.0.92` |
| `no attribute 'getConnectionId'`（pybullet） | 新版 pybullet API | 用 `getConnectionInfo()["isConnected"]`（代码已处理） |
| `QFontDatabase: Cannot find font directory` | OpenCV 窗口字体提示 | **无害，忽略** |
| `--robot.type: invalid choice` | 机器人类型没注册 | 代码里已 `import lerobot.robots.so_follower` |

## 1.10 LeRobot main 分支 API 速查（本项目用到的）

| 旧 0.6.1 写法 | main 分支写法 |
|---|---|
| `RobotConfig.from_cli()` | `@parser.wrap()` + `make_robot_from_config(cfg.robot)` |
| `robot.get_observation_dict()["observation.state"]` | `robot.get_observation()["shoulder_pan.pos"]` |
| `robot.absolute_move(action, duration)` | `robot.send_action({电机名.pos: 值})` |
| `robot.motor_names` | 不存在（`robot_lib` 已自动补上） |
| 机器人类型自动注册 | 需先 `import lerobot.robots.so_follower` |

这些差异已经全部封装在 `robot_lib.py` 里，日常使用不需要关心。
